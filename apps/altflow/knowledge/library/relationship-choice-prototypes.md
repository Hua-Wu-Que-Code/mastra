# 关系抉择原型

适用于「情感抉择」类作品，是关系线设计、选项原型、状态变量、分集互动节点和反馈规则的参考。

## 关系模式

| 模式 | 场景 | 用户在选什么 | 设计重点 |
|---|---|---|---|
| 1v1 深度拉扯 | 单一核心关系，强调误会、破裂、修复、信任重建 | 如何靠近、疏离、坦白、隐瞒、原谅或切断 | 做深一条关系线，追踪好感、信任、误会和关系阶段 |
| 1vN 多人选择 | 多个可偏爱的对象并行，强调路线差异和修罗场 | 回应谁、拒绝谁、端水谁、当众站到谁身边 | 至少影响两个对象的状态差异，中后段形成锁线或强偏好 |
| 多人关系网 | 爱情、亲情、友情、利益共同施压 | 如何处理不同关系之间的冲突和代价 | 不只看恋爱对象，也记录证据、友情、家人、盟友等状态 |

## 状态字段

| 字段 | 含义 | 展示建议 | 是否必备 |
|---|---|---|---|
| 好感 | 对象对主角的情感倾向 | 可轻量展示为关系温度，不一定显示数值 | 必备 |
| 信任 | 对象是否相信主角的解释、选择和立场 | 适合误会、坦白、隐瞒类选择 | 必备 |
| 嫉妒 | 多对象关系中的竞争和吃醋程度 | 适合 1vN、修罗场、当众选择 | 可选（1vN、关系网） |
| 占有 | 对象是否试图控制、绑定或独占主角 | 适合危险吸引、契约关系、强控制角色 | 可选 |
| 风险 | 关系是否带来舆论、伤害、黑化或主线代价 | 适合提示「这条关系有代价」 | 可选 |

## 互动题型样例

| 题型 | 问题 | 选项方向 | 状态后果 | 适用模式 |
|---|---|---|---|---|
| 接谁的电话 | 当前危机里先回应谁 | 接旧爱 / 回守护者 / 两个都不回 | 被回应对象好感、信任上升，未被回应对象嫉妒上升或信任下降 | 1vN、关系网 |
| 是否坦白秘密 | 关系逼问时说真话还是继续隐瞒 | 坦白旧案 / 继续隐瞒 / 反问对方 | 坦白提升信任但增加风险；隐瞒维持局面但埋下反噬 | 全部 |
| 当众选择谁 | 修罗场里公开站到谁身边 | 跟旧爱走 / 留在守护者身边 / 接受权力对象安排 | 进入路线锁定或强偏好，未被选择对象疏离、嫉妒或撤回资源 | 1vN |
| 是否接受靠近 | 对方释放靠近信号时回应还是后退 | 主动靠近一步 / 用玩笑挡开 / 直接拒绝触碰 | 靠近提升亲密和占有感；回避保留距离但可能增加误会 | 1v1、1vN |
| 回应试探 | 对象用暧昧或逼问试探时给什么反馈 | 顺着话承认在意 / 反问真实目的 / 转移话题离开 | 正面回应提升信任或亲密；反问增加张力；逃避增加误会或风险 | 全部 |
| 是否公开关系 | 面对外界压力时公开还是继续隐瞒 | 当众承认 / 只私下安抚 / 继续否认牵连 | 公开带来关系确认和舆论风险；隐瞒保住资源但伤害信任 | 全部 |

## 关系钩子

- **误会升级**：选择后对方只看到片段事实，关系没有解释完。
- **被忽视对象受伤**：未被选择的人出现疏离、冷脸或资源撤回。
- **旧秘密暴露**：隐藏身份、旧案、契约或白月光真相被抛出。
- **关系反转**：原本冷淡的人主动靠近，原本的守护者开始退后。
- **未选对象异化**：嫉妒、占有或黑化的风险开始积累。

## 关系弧线阶段

1. **初遇试探**：建立对象魅力、边界和第一印象。
2. **误会拉扯**：把关系问题压到选择前，选择后立刻给情绪反馈。
3. **暧昧升温**：用靠近、试探、秘密交换制造亲密感。
4. **修罗场施压**：让至少两个对象感知到主角选择的偏向。
5. **锁线或代价兑现**：不同对象进入不同的态度、帮助或疏离状态。

## 分集互动节点要写的内容

每集的互动节点包括：本集情绪目标（心动、试探、误会、修罗场、代价兑现或结局确认）、出场角色、互动节点（用户在什么剧情压力下做情感选择）、数值后果（影响哪些对象的好感、信任、嫉妒、占有或风险）、结尾钩子（因选择引发的关系追问、误会升级、证据暴露或态度变化）、按钮文案方向。

按钮必须带情绪动作，例如「点开他的照片」「先问病历真相」，避免「选 A / 选 B」。

## 1vN 选项设计铁律

1. 不能只写「选 A / 选 B / 选 C」，必须写成具体的情绪动作。
2. 每个选项至少影响两个对象，例如 A 好感上升，同时 B 信任下降或嫉妒上升。
3. 中段要出现修罗场或路线压力，让用户感到「端水也有代价」。
4. 锁线节点不一定强制唯一结局，但要让最高好感、最高信任或关键选择影响后续专属剧情。
5. 主线仍可合流，但不同对象的台词温度、开场态度、是否主动帮助必须有差异。
