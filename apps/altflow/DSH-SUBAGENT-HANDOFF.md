# DSH 子智能体机制：合并复审与补齐

更新：2026-11-18。此前暂停记录已结束；用户要求合并同事分支并补齐 DSH 机制。

同事交付的固定 researcher/editor 前台委派不满足动态创建要求。生产入口已替换为 `subagents/agents.ts`，删除固定助手实现与旧委派容量池，仅保留统一执行策略。

## 运行契约

- `subagent` / `subagent_fork` 返回创建结果后在后台运行；分叉仅复制已完成轮次。
- `list_agents`、`send_message`、`wait_agent`、`interrupt_agent` 控制当前会话树。用户插话也能唤醒等待；中断保留历史，可发送消息继续。
- 团队开关只控制 `team_task_create/get/list/update` 与协作指令。关闭不会禁用普通子智能体或删除已有任务。
- 共享任务持久化，修改校验 revision、任务归属、依赖环及前置完成状态；文件范围冲突是提示。
- 活跃容量默认 8，最大深度 1，工具并发默认 10；无产品固定步数上限。
- 每个子智能体有私有 Memory resource；身份与账号文件授权继承服务端已验证的账号。客户端不能提交保留身份键。
- LibSQL 保存会话树、收件箱和任务。过期运行在根会话收到新验证的账号上下文后恢复；generation 防止旧激活覆盖中断后的状态。
- 子运行应用相同的上下文压缩器；无独立的 20 条截断机制。
- 交互式提问与计划审批由主智能体处理，子智能体通过消息请主智能体介入。

## 界面

普通会话左上角显示会话名称。有子智能体时显示数量菜单；每行展示创建描述、名字、状态、实际 Token 总量与累计运行时间。没有用量时显示“未提供”。

子会话用 URL `?child=<id>` 定位，显示“主会话 / 子智能体”，可返回、切换、翻页读取历史、继续发送或停止。普通历史侧栏不显示这些私有子会话。共享任务板仅在团队开启且已有任务时显示。

`GET/POST /altflow/subagents` 每次验证账号和主会话所有权；子 ID 必须属于该树。Cookie 写请求校验 Origin，限制实际读取的请求体大小。用量来自真实运行返回值，前端不估算。数据库和文件账本是唯一业务数据来源。

## 参考与验证边界

参考源码：DeepSeek Harness 的 `packages/subagent`、`packages/team`、`packages/client/ui-subagent`、`packages/client/ui-agent-team`。

自动测试使用真实 Agent、LibSQL、HTTP、文件适配器和 UI hooks；付费模型与外部 OSS/Go 认证服务的网络边界使用协议样本。覆盖动态 9 次工具调用、身份隔离、并发容量、异常恢复、用户插话、中断继续、冷恢复、任务 revision 与 UI 导航。冷恢复测试创建新的运行管理器；不是实际杀进程故障注入。

独立搜索凭据尚未配置，真实联网搜索不在通过项中。当前运行管理器使用单进程协调；持久租约用于重启恢复，不宣称支持跨机器自动故障接管。

## 最终本地验证

- 工具与子智能体测试 24/24；原有应用回归 40/40。两组有重叠，不合并计数。
- Studio 会话相关测试 60/60、工具目录 4/4、组件库定向测试 3/3；工具包测试 5/5。
- 类型检查、受影响文件 lint、双语检查和 Studio/组件库/工具包构建通过。
- 真实浏览器核对已有会话标题与文件面板；修正 Vite 缺少 `/altflow` 代理导致返回 HTML 的问题。子会话导航及输入用真实 hooks 与 HTTP 协议样本验证，尚未执行付费模型的浏览器全流程。
- 容量满时继续子会话，先校验接收容量再保存输入；被拒绝的输入不会成为历史消息。
- 本地 `pnpm --filter @internal/altflow start` 使用 `start-built.mjs` 打包后启动，复用当前安装并验证过的框架依赖，避免开发发现进程与运行进程争用 DuckDB。该入口不是独立部署包：独立部署仍需携带对应的本地框架构建，不能换成同版本的未经补丁的公开包。
- 本地运行端口：4111 API、5174 Studio、8080 账号服务。补齐代码保留为未提交修改，未推送。
